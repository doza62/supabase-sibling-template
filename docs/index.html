How this works

This page is 100% client-side. No server, no tracking. All data stays in your browser's localStorage.

Categorization rules:

  • Hostnames: POSTGRES_HOSTNAME, MINIO_HOSTNAME, ANALYTICS_HOSTNAME
  • Shared secrets: any SERVICE_PASSWORD_*, SERVICE_USER_MINIO, SUPABASEANON_KEY, SUPABASESERVICE_KEY, SECRET_PASSWORD_REALTIME
  • Per-sibling: POSTGRES_DB, STUDIO_DEFAULT_PROJECT, STORAGE_TENANT_ID, API_EXTERNAL_URL, GOTRUE_SITE_URL, SERVICE_USER_ADMIN, SERVICE_PASSWORD_ADMIN

Other env vars (SMTP_*, OPENAI_API_KEY, etc.) are passed through as shared.
